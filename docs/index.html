  1. Write it like any note.

    Markdown, tabs, a terminal beside it. Nothing special until the note is one you wouldn't paste into a chat.

  2. Lock it.

    Pick a folder: SSH, Logins, Recovery codes. The note becomes an encrypted .nqv file. Argon2id and XChaCha20-Poly1305, with a recovery key shown once.

  3. Sync only ciphertext.

    Connect your own Telegram bot (Google Drive is next). Files go up under random names, so titles and folders never leave the app.

  4. Open it on another machine.

    Install Notiq, choose Restore from Telegram, enter your master password. Conflicts keep both versions; sync never deletes anything.

Everything else you'd expect

Editor
Monaco-based Markdown editing with live preview, tabs and a built-in terminal.
Whiteboard
Sketch next to your notes; drawings stay with the tab.
Knowledge graph
Link notes with wiki-style links and see how they connect.
Local-first
Files on your disk. AI is optional, off by default, and only talks to the Ollama endpoint you configure.

Get started

  1. Download the installer for your system from the latest release.
  2. Write as usual. When a note is private, lock it and pick a vault folder.
  3. Optional: connect Telegram in Settings → Vault to keep your other machines in step.
