Sign-up forms with password rules

1. maxlength=16

The generated password must be 16 characters, in both fields.

2. passwordrules

minlength 8, maxlength 14, lower + upper + digit required, only -_. as symbols.

3. pattern, letters and digits only

pattern="[A-Za-z0-9]{8,12}": 12 characters, no symbols.

4. impossible rules

minlength 30 but maxlength 10: Notiq warns and fills its default password, cut to the 10-character maximum.

5. script cuts to 10

No maxlength attribute; a script keeps only the first 10 characters. Notiq retries at 10.
